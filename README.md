Este repositório contém o código-fonte da landing page institucional da **TechForge Solutions**, uma empresa fictícia de desenvolvimento de software criada como projeto acadêmico para o curso técnico da **ETEC Basildes de Godoy**.

## 📋 Sobre o Projeto

O objetivo deste projeto foi criar uma presença digital moderna, limpa e responsiva para uma empresa de tecnologia, aplicando conceitos de design de interface (UI), experiência do usuário (UX) e desenvolvimento front-end. A identidade visual, cores, tipografia e textos foram baseados estritamente no manual da marca e nos slides de apresentação fornecidos.

## ✨ Funcionalidades

- **Design Responsivo:** Adapta-se a diferentes tamanhos de tela (desktop, tablet e mobile).
- **Menu Mobile (Hambúrguer):** Navegação otimizada para dispositivos móveis.
- **Scroll Suave:** Transição fluida entre as seções da página.
- **Scroll Reveal:** Animações de surgimento nos elementos conforme a rolagem da página.
- **Botão "Voltar ao Topo":** Facilita a navegação em páginas mais longas.
- **Tecnologias:** Seção dedicada para mostrar a stack tecnológica da empresa com ícones interativos.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando apenas tecnologias web fundamentais (Vanilla Web), sem o uso de frameworks ou bibliotecas pesadas de JavaScript:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout com Flexbox/Grid e animações.
- **JavaScript (ES6+):** Manipulação de DOM, controle do menu mobile e Intersection Observer para animações.
- **Google Fonts:** Fontes *Barlow Condensed* (Títulos) e *DM Sans* (Corpo do texto).
- **FontAwesome:** Biblioteca de ícones vetoriais.
- **SVG:** Logotipo da empresa recriado vetorialmente para garantir alta qualidade em qualquer tela.

## 🎨 Paleta de Cores e Tipografia

A identidade visual foi baseada nas diretrizes dos slides:

- **Cores Principais:**
  - Azul Escuro (Principal): `#004AAD`
  - Ciano (Destaque): `#5CE1E6`
  - Fundo Claro: `#F1F5F9`
- **Tipografia:**
  - Títulos: `Barlow Condensed` (Moderna e Geométrica)
  - Textos: `DM Sans` (Fácil Leitura)

Como o projeto é estático (não possui back-end ou dependências complexas), você pode executá-lo de duas formas simples:

1. **Modo Direto:** Basta fazer o download dos arquivos e dar um duplo clique no arquivo `index.html`. Ele abrirá no seu navegador padrão.
2. **Usando o VS Code:** Se preferir, abra a pasta no Visual Studio Code e utilize a extensão *Live Server* para visualizar o projeto com recarregamento automático.
